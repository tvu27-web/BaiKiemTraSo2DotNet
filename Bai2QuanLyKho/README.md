## Hướng dẫn chạy

1. Clone repository:
```bash
   git clone <đường-dẫn-repository>
```
2. Mở file `.sln` bằng Visual Studio (chỉ chạy được trên Windows).
3. Nhấn **F5** để chạy chương trình.

Hoặc dùng dòng lệnh:

```bash
dotnet run --project Bai2QuanLyKho
```
